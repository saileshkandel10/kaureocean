# Design System: Kaure Ocean Platform

## 1. Color Palette
Derived from Kaure Ocean's brand identity:
- **Primary Navy:** `#203070` (Used for headers, primary buttons, major section backgrounds)
- **Dark Navy:** `#172B60` (Used for footers, navbar, contrast text)
- **Accent Orange:** `#E05020` (Used for CTAs, highlights, badges, icons)
- **Background Cream:** `#F5F1E8` (Used for subtle card backgrounds, alternating sections)
- **Neutral White:** `#FFFFFF` (Used for clean content cards, main background)
- **Text Dark:** `#222222` (High readability body text)

## 2. Typography
- **Primary Font Family:** Inter, Roboto, system-ui, -apple-system, sans-serif
- **Headings:** Bold weight (700/800), Primary Navy or Dark Navy
- **Body Text:** Regular weight (400), Text Dark (`#222222`), 16px base size
- **Line Height:** 1.6 for body, 1.2 for headings

## 3. UI Components
- **Navbar:** Sticky top, branded logo, clear navigation links, phone contact badge, and "Apply Now" button.
- **Hero Section:** High-impact background, compelling headline ("Train, Deploy and Support"), dual CTA buttons.
- **Cards:** Clean white background, subtle border/shadow, rounded corners (`border-radius: 8px`), orange accent highlights.
- **Buttons:** Rounded, solid background for primary actions (Navy or Orange), clear hover transitions.
- **Forms:** Clean input fields with floating labels or clear placeholders, validation feedback styling.
- **Footer:** Dark Navy background `#172B60`, multi-column layout with contact details, license number (221/082/083), social links, and copyright.
